## 2. Payment Processing Concepts Learned

- Debt retirement may not rewrite already-correct payment truth. Generator
  resume and webhook administration must remain outside money-movement
  transactions and rely on stable public-API idempotency.

## 3. Fraud Detection Concepts Learned

- Trusted synthetic origin is decision-time lineage, not merchant metadata.
  Phase 3 features and later ML datasets must be able to exclude or segment
  synthetic traffic using a server-assigned immutable fact.

## 4. Security Concepts Learned

- Lost-response recovery for one-time webhook secrets is a security protocol:
  endpoint idempotency must recover the original authorized response without
  persisting plaintext or minting a second active endpoint.
- Secret rotation is a generation protocol. A claimed delivery must retain the
  generation it is authorized to use, and the previous key is valid strictly
  before—not at—its expiry.
