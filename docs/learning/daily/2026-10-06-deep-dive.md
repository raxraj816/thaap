## System Goal And First Principles

Phase 6 was already implemented and merged. This continuation repairs its
completion governance, not its product runtime. A gate is an executable decision:
it reads evidence, rejects contradictions and returns a nonzero exit when the
claim is not justified. Printing reassuring output is not the decision; the exit
code is. A gate that readiness never invokes provides no protection.

This matters in a payment-risk product because a false readiness claim can hide
missing tenant, fraud-lineage or concurrency proof. Governance does not create
that product truth; it checks that the independently enforced proof exists.

the application unit suite stays green. The audit froze repair promises before touching code
and reopened scope before each newly reproduced demo family (`ER-0109`–`ER-0116`).

The edge must distinguish API from UI navigation before looking at response status. Otherwise
turning a 403/404 into a 200 shell conceals authorization failures. Sixteen published public
roots and four operational roots now agree across Vite, nginx, smoke and Terraform; a separate
OpenAPI-derived comparison prevents four equally incomplete lists agreeing with each other.
Forwarded identity is rebuilt at the first trusted hop while tenant credentials, query bytes
and idempotency keys remain untouched. WAF rate evaluation precedes its terminating allow.
CloudFront mock execution and real nginx sockets prove separate boundaries; neither proves a
live AWS allowlist. ACM certificates for one hostname use one statically addressed DNS record

Kafka durability depends on the directory the broker writes, not whether a volume exists.
The real proof produces a record, commits a consumer offset, removes the container, retains
only its volume, replaces it, and reconciles old/new records plus the next committed offset.
Local Docker-volume success does not prove EFS permissions, AWS task replacement or HA.
Project-scoped names and refusal before cleanup protect another developer's persistent data.
