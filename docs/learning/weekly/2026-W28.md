## Engineering lessons

- A deterministic credential needs both replay inputs and a lifecycle epoch.
- Authorization and exact use must share a lock when mutable state can change
  between them.
- Retry classification is product semantics: a stale snapshot can converge,
  while integrity or permanent configuration failure must remain distinct.
- An enable flag for one worker cannot suppress dependency readiness for other
  reachable administration/replay capabilities.
- Lease fencing is proven only when ownership is locked before protected work
  and expiry is forced while that work is still blocked.
