# payments-api

Primary V1 backend deployable.

Planned stack:

- Java 21
- Spring Boot 3
- Spring Web
- Spring Validation
- Spring Data JPA
- Flyway
- Spring Actuator
- PostgreSQL
- Redis

Responsibilities:

- merchant, customer, and payment method APIs
- PaymentIntent and PaymentAttempt lifecycle
- idempotency
- fraud decision orchestration
- deterministic rules
- manual review
- processor simulation orchestration
- authorization, capture, cancel, refund, and chargeback flows
- ledger writes
- webhook records
- audit logs
- outbox events

This directory is intentionally a placeholder on Day 1. The Spring Boot scaffold begins in the foundation implementation work.
